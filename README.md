# Matdori
- 실제 방문자의 진솔한 경험과 리뷰를 바탕으로 지역별 맛집을 탐색하고, 나만의 미식 경험을 기록·공유하는 맛집 SNS 플랫폼 형식의 앱입니다. (현재 목업단계입니다.)

## Features

-  맛집 저장 기능: SNS형식으로 맛집이나 직접 검색한 맛집을 저장하고 관리합니다.
-  지역별 맛집 검색: 원하는 지역을 선택하여 해당 지역의 맛집을 검색하고 확인할 수 있습니다.
-  개인 별점 및 리뷰: 직접 방문한 맛집에 자신만의 별점과 리뷰를 작성할 수 있습니다.
-  맛집 공유 기능: 자신이 발견하거나 방문한 맛집을 다른 사용자들과 공유할 수 있습니다.
-  상세 매장 정보: 영업시간, 메뉴, 음식 및 매장 사진, 주차장, 화장실 등의 정보를 확인할 수 있습니다.
